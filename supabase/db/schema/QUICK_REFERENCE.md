## Table Overview

### places

- **Purpose**: Geographic locations with semantic descriptions
- **Key Columns**: id, name, embedding (vector 384), geom (PostGIS), pending_review
- **Indexes**: 8 (HNSW for embeddings, GiST for geography)
- **RLS**: Public read, service role write, users can delete own

### questions

- **Purpose**: Questions for narrowing candidates
- **Key Columns**: id, text, embedding (vector 384), question_type, effectiveness_score
- **Indexes**: 5 (HNSW for embeddings, B-tree for effectiveness)
- **RLS**: Public read, service role write

### game_answers

- **Purpose**: Q&A pairs during gameplay
- **Key Columns**: id, session_id, question_id, answer, candidates_after
- **Indexes**: 4 (session, sequence, question lookups)
- **RLS**: Users can access own session answers

### game_sessions

- **Purpose**: Game session state and metadata
- **Key Columns**: id, user_id, place_id, session_status, current_question_id, pending_guess_place_id
- **Indexes**: 7 (active sessions, user history, place history)
- **RLS**: Users can access own sessions (supports anonymous)

## Vector Configuration

All embeddings use **384 dimensions** (all-MiniLM-L6-v2 model):

- Generated by edge function `generate-embedding`
- Stored as `vector(384)` in pgvector
- Indexed with HNSW for fast similarity search
- Cosine distance metric

## PostGIS Configuration

All geometries use **SRID 4326** (WGS84):

- `places.geom` - GEOMETRY(Point, 4326)
- Indexed with GiST for spatial queries
- Used for geographic question filtering

## RLS Key Features

- **UUID-Based Ownership**: All users (including anonymous) have auth.uid(); policies use user_id = auth.uid()
- **Service Role**: Can bypass RLS for admin operations
- **Cascade**: Deleting sessions cascades to answers
- **Idempotent**: DROP IF EXISTS before CREATE POLICY

## Trigger Functions

Located in `supabase/db/functions/utilities/`:

1. **approve_pending_session()** - Upserts places from approved sessions
2. **enrich_place_on_approval()** - Enriches approved places
3. **enrich_place_on_session_complete()** - Enriches places from successful guesses
4. **touch_session_last_activity()** - Updates session activity timestamp

## Common Queries

### Find active sessions

```sql
SELECT
  *
FROM
  game_sessions
WHERE
  session_status = 'active'
ORDER BY
  last_activity_at DESC;
```

### Find top questions by effectiveness

```sql
SELECT
  *
FROM
  questions
ORDER BY
  effectiveness_score DESC,
  times_asked DESC
LIMIT
  10;
```

### Find candidates for a place

```sql
SELECT * FROM places
WHERE embedding IS NOT NULL
ORDER BY embedding <=> (SELECT description_embedding FROM game_sessions WHERE id = $1)
LIMIT 10;
```

### Check pending places

```sql
SELECT
  *
FROM
  places
WHERE
  pending_review = true
ORDER BY
  created_at DESC;
```

## Maintenance Tasks

### Rebuild HNSW indexes

```sql
REINDEX INDEX idx_places_embedding_hnsw;

REINDEX INDEX idx_questions_embedding_hnsw;
```

### Check index sizes

```sql
SELECT
  schemaname,
  tablename,
  indexname,
  pg_size_pretty (pg_relation_size (indexrelid))
FROM
  pg_indexes
WHERE
  tablename IN (
    'places',
    'questions',
    'game_answers',
    'game_sessions'
  )
ORDER BY
  pg_relation_size (indexrelid) DESC;
```

### Analyze query performance

```sql
EXPLAIN ANALYZE
SELECT * FROM places
WHERE embedding IS NOT NULL
ORDER BY embedding <=> $1::vector
LIMIT 10;
```

## Troubleshooting

### RLS blocking queries

- Check `auth.uid()` is set correctly
- Verify policy conditions with `SELECT * FROM pg_policies`
- Test with `SET ROLE` to simulate different users

### Slow embedding searches

- Check HNSW index exists: `SELECT * FROM pg_indexes WHERE indexname LIKE '%embedding%'`
- Verify vector dimension matches: `SELECT pg_typeof(embedding) FROM places LIMIT 1`
- Rebuild index if needed: `REINDEX INDEX idx_places_embedding_hnsw`

### Trigger not firing

- Check trigger exists: `SELECT * FROM pg_trigger WHERE tgname LIKE '%trigger_name%'`
- Verify function exists: `SELECT * FROM pg_proc WHERE proname = 'function_name'`
- Check trigger is enabled: `ALTER TABLE table_name ENABLE TRIGGER trigger_name`
