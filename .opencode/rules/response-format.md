# Response Format

Read this before completing your response.

## Required Sections

End EVERY response with these sections:

```
## Changes Made
- [file:line] Description of change
- [file:line] Description of change

## Issues Found (Not Fixed)
- [issue] Why not fixed: outside task scope
- None (if no issues found)

## Warnings
- [warning] Any concerns about the implementation
- None (if no warnings)
```

## Rules

- Be specific about file paths and line numbers
- List ALL files you modified
- If you found issues but didn't fix them, explain WHY (task scope)
- If implementation has risks, warn about them
