# MCP Servers

## Configured

- **Context7** - Documentation lookup (Vue, Supabase, TypeScript, MapLibre, pgvector)
- **Serena** - Code analysis and research (activated for this project)
- **Playwright** - Browser automation for E2E testing (built-in)

## Usage

Reference them naturally in prompts:
- "Use Context7 to show me Supabase RLS examples"
- "Use Serena to research vector embedding strategies"
- "Use Playwright MCP to test the home page and create test specs"

## Playwright MCP Capabilities

- Navigate to pages and take snapshots
- Interact with UI elements (click, type, hover)
- Capture console logs and network requests
- Take screenshots for debugging
- Design and validate E2E tests

All work immediately, no setup needed.
