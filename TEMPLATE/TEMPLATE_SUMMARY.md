## 🚀 Quick Start

1. **Copy Template**
   ```bash
   cp -r TEMPLATE my-new-project
   cd my-new-project
   ```

2. **Run Setup**
   ```bash
   ./scripts/setup-project.sh
   ```

3. **Configure Environment**
   ```bash
   cp env.example .env.local
   # Edit .env.local with your values
   ```

4. **Start Development**
   ```bash
   npm run dev
   ```
